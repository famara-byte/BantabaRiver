## What is in this repository

| File | Purpose |
| --- | --- |
| `index.html` | The complete website — one self-contained static page (HTML, CSS and JS in a single file). |
| `space.json` | Site configuration / blueprint: runtime `static`, entry point `index.html`, site name and slug (`bantaba-river-eco-tourism-website`). |
| `AGENTS.md` | Build notes: how the site is structured, built and published. |
| `README.md` | This file. |

## Site blueprint

- **Type:** static single-page website — no server, no database.
- **Sections:** Hero · About · Experiences · Sustainability · Contact (plus mobile navigation).
- **Page title:** "Bantaba River & Eco-Tourism — Discover The Gambia... Naturally!"
- **Images:** the live build carries its photographs under `assets/` (river, mangroves, birdwatching, village, Fathala lions, Albert Market and more). Those image files are binary and are not stored in this repository yet — they live in the published site build.

## Publishing

The site is built and published as a hosted web page from this source. To update it, edit `index.html` (keeping `space.json` as the configuration) and republish, or ask Muse to make the change and push the updated code here.
